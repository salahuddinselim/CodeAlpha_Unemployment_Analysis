# CodeAlpha_Unemployment_Analysis

CodeAlpha Data Science Internship — Task 2.

Cleans, explores, and visualizes India's regional unemployment rate, quantifies the
Covid-19 lockdown impact, breaks down rural vs urban and state/zone level trends, and
derives policy-relevant insights.

## Run

```
cd CodeAlpha_Unemployment_Analysis
jupyter notebook unemployment_analysis.ipynb
```

Select the **Python 3 (CodeAlpha DS)** kernel.

## Dataset

`data/Unemployment in India.csv`, `data/Unemployment_Rate_upto_11_2020.csv` —
[Kaggle: gokulrajkmv/unemployment-in-india](https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india)
